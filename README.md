# הכסף שלי

אפליקציה לניהול הכנסות והוצאות לבית: חלוקת משכורת לקטגוריות, תקציב לכל קטגוריה, התראות חריגה, יעד חיסכון חודשי וצילום קבלות.

**כתובת:** https://enoshc.github.io/kesef/

- מתקינים בטלפון דרך "הוסף למסך הבית", ועובדת גם בלי אינטרנט.
- ייבוא מאקסל, מגוגל שיטס ומדוחות בנק (xlsx, xls, csv), עם שיוך אוטומטי לקטגוריות.
- ניהול משותף: מחברים גיליון גוגל שיטס עם הסקריפט שב־`apps-script.gs`, ומשתפים קוד הצטרפות. כל שינוי מגיע לכל המחוברים ולגיליון, ואפשר לערוך גם ישירות בגיליון.
- הנתונים נשמרים במכשיר של כל משתמש, ובסנכרון גם בגיליון ובדרייב של המשתמש. אין שרת חיצוני.
- חיובים נכנסים לבד: הודעות SMS מחברת האשראי ומהבנק נשלחות לגיליון דרך קיצור דרך באייפון (או MacroDroid באנדרואיד), ונקלטות עם סכום, בית עסק וקטגוריה, בלי לחבר את החשבון ובלי סיסמאות.
- הודעות בין כל המחוברים לחשבון, ואלבום תמונות משותף שמתחלף ברקע.
- הוצאות קבועות שנכנסות לבד, צפי לסוף החודש, תגיות, למידת קטגוריות, דוחות ומגמות, וסיכום שבועי במייל.
- גיבוי ושחזור מקובץ, ייצוא ל־Excel ול־CSV.
- סוגי קטגוריות: הוצאה, חיסכון והשקעות, הכנסה והעברה בין החשבונות שלך (לא נספרת). זיכוי בקטגוריית הוצאה מקטין אותה, ומשיכה מחיסכון מקטינה את החיסכון.
- ייבוא חכם של פירוט max ועו"ש Pepper יחד: כל הגיליונות, דילוג על החיוב החודשי של הכרטיס ועל כפילויות, זיהוי זיכויים, העברות עצמיות והשקעות, ונקודת התחלה ליתרה.
- בנק וכרטיס: בדיקת יתרה מול הבנק, צפי לחיוב הכרטיס הבא, התראה לפני מינוס ותשלומים עתידיים.
- מנויים, טיולים, חלוקת הוצאות עם חברים, תיבת "לבדיקה" לחיובים שנקלטו לבד ועורך כללים.
- הוספה בקול עם סירי, וידג'ט למסך הבית (Scriptable), נעילה עם Face ID או קוד, שותף לצפייה בלבד וקוד QR להצטרפות.
- עדכונים אוטומטיים לסקריפט: `loader.gs` מושך את `apps-script.gs` העדכני מ־GitHub (אופציונלי).
- `qrcode.js`: QR Code Generator של Kazuhiko Arase, רישיון MIT.
